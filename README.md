# Student Record Management (Java)
Object-Oriented Java program to manage student records, display data, and calculate grades.

## Overview
This **Java-built student record management system project** serves as an example of fundamental Object-Oriented Programming (OOP) ideas.
It enables users to:

- Add Student Records: Enter the student's name, course, roll number, and grades.

- Display Records: Access all of the student data that has been saved in a clear, menu-driven interface.

- Automatic Grade Calculation: Based on marks, assign letter grades (A–D/F).

The system, which was constructed as a Java programming lab assignment, features:

- A student class with fields (rollNo, name, course, marks, and grade) and methods for entering, displaying, and computing grades is known as a class-based design.

- Menu-Driven Console UI: To add and view records, users interact with a straightforward text menu.

- Data structures: Using an array or ArrayList to manage several students.

- Java Fundamentals: Loop control, conditional logic, constructors, and methods for program flow.

## Features
- **OOP Concepts**: Inheritance, Constructors, Methods  
- **ArrayList**: Manage multiple student records  
- **Methods Implemented**:
  - `inputDetails()` → Add student details  
  - `displayDetails()` → Display student information  
  - `calculateGrade()` → Assign grade based on marks  
- **Menu-based Interaction**: Simple CLI menu with `Scanner`
